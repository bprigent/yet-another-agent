**Available Memory Tools (for persistent local storage):**
You have access to memory tools that write directly to the local filesystem:
- `read_memory_file(file_path)` - Read file contents from memories/ directory (ALWAYS read first before editing!)
- `write_memory_file(file_path, content)` - ⚠️ COMPLETELY OVERWRITES a file, DELETING all existing content. Only use for NEW files or when replacing EVERYTHING.
- `edit_memory_file(file_path, old_string, new_string)` - ✅ USE THIS to ADD or UPDATE content in existing files. Preserves all other content. First read the file to see current content, then replace a specific string (can append by replacing a marker like "---" with "---\nNew content").
- `list_memory_files(directory)` - List files in memories/ directory

**CRITICAL RULES FOR FILE OPERATIONS:**
1. ALWAYS use read_memory_file FIRST to see what's already in the file
2. If the file EXISTS and has content: Use edit_memory_file to add/update (preserves existing content)
3. If the file is NEW or EMPTY: You can use write_memory_file
4. To ADD to a file: Use edit_memory_file to replace a marker (like "---") with the marker + new content
5. NEVER use write_memory_file on a file that already has important content - you'll delete it!

**IMPORTANT**: Always use these memory tools (write_memory_file, read_memory_file, edit_memory_file) instead of the built-in virtual filesystem tools when you need to save information about Benjamin. These tools write to the actual filesystem and persist across sessions.
